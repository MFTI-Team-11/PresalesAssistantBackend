│# AI ассистент для пресейла                                                                                                                                                                                                           │
│                                                                                                                                                                                                                                      │
│## Название Кейса                                                                                                                                                                                                                     │
│AI ассистент для пресейла                                                                                                                                                                                                             │
│                                                                                                                                                                                                                                      │
│## Краткое описание кейса                                                                                                                                                                                                             │
│Оценка IT-проектов — процесс долгий, дорогой и трудозатратный. Он требует участия разных специалистов: аналитик, разработчик, тестироващик, архитектор, дизайнер и  руководитель проекта, но при этом сам пресейл — этап некоммерчески│
│й, итог — «плавающие» сметы, выгоревшие сотрудники и низкая конверсия. Для IT компаний, где каждый проект уникален, точная и быстрая оценка особенно важна.                                                                           │
│                                                                                                                                                                                                                                      │
│## Ожидаемый результат                                                                                                                                                                                                                │
│В результате ожидается  получить AI ассистента для пресейла, который будет помогать в первичной оценке.                                                                                                                               │
│                                                                                                                                                                                                                                      │
│## Основной функционал                                                                                                                                                                                                                │
│Что должен уметь делать AI ассистент:                                                                                                                                                                                                 │
│1. Принимать для анализа документы (текст, таблицы, вложенные файлы). Ставки по специалистам (придумать самостоятельно)                                                                                                               │
│2. Задавать вопросы для преданализа                                                                                                                                                                                                   │
│3. Формировать ФТ и НФТ                                                                                                                                                                                                               │
│4. Декомпозировать задачи                                                                                                                                                                                                             │
│5. Определять и рекомендовать архитектуру решения.                                                                                                                                                                                    │
│6. Просчитывать сайзинг для выбранного решения                                                                                                                                                                                        │
│7. Оценивать длительность проекта в зависимости от состава команды разработки                                                                                                                                                         │
│8. Предлагать варианты состава команды (включая роли, требуемый уровень специалистов) без простоя                                                                                                                                     │
│9. Рассчитывать трудозатраты команды.                                                                                                                                                                                                 │
│10. Рассчитывать трудозатраты и бюджет тех. поддержки после окончания проекта (предусмотреть возможность выбора схем  поддержки:                                                                                                      │
│   - Вариант 1: 1,2,3 линии поддержки 24*7*365.                                                                                                                                                                                       │
│   - Вариант 2: только 3 линия поддержки с 6:00-18:00    рабочие дни.                                                                                                                                                                 │
│11. Оценивать расходы на годовое гарантийное обслуживание и включать эти расходы в проект.                                                                                                                                            │
│12. Оценивать риски проекта и готовить план митигации на основании ответов на поставленные вопросы.                                                                                                                                   │
│13. Результат пресейла формировать в единый документ по заданному шаблону (шаблон придумать самостоятельно)                                                                                                                           │
│14. СУММИРОВАТЬ РАСХОДЫ ПО МЕСЯЦАМ                                                                                                                                                                                                    │
│                                                                                                                                                                                                                                      │
│## Дополнительные требования                                                                                                                                                                                                          │
│Нефункциональные требования и ограничения:                                                                                                                                                                                            │
│1.On-premise (он-прем) — это модель использования IT-инфраструктуры и программного обеспечения, при которой серверы, данные и приложения размещаются непосредственно на территории компании или в ее собственном дата-центре, а не в о│
│блаке                                                                                                                                                                                                                                 │
│2.  Объем преселов  в месяц - 30-50                                                                                                                                                                                                   │
│                                                                                                                                                                                                                                      │
│Не передавать данные за пределы  компании                                                                                                                                                                                             │
│                                                                                                                                                                                                                                      │
│Критерии приемки:                                                                                                                                                                                                                     │
│1. Подготовлена и описана архитектурная схема.                                                                                                                                                                                        │
│2. Описаны внешние системы для интеграции.                                                                                                                                                                                            │
│3. Реализован AI ассистент                                                                                                                                                                                                            │
│4. Описаны ограничения, допущения, риски разработанного ПО                                                                                                                                                                            │
│5. Продемонстрирован основной функционал (список из 13 пунктов)                                                                                                                                                                       │
│                                                                                                                                                                                                                                      │
│## Пример использования                                                                                                                                                                                                               │
│Сценарий:                                                                                                                                                                                                                             │
│1. пользователь запускает новый  запрос на прессейл                                                                                                                                                                                   │
│2. Пользователь загружает данные от  заказчика (бизнес требования ФТ)                                                                                                                                                                 │
│3. Пользователь загружает ставки                                                                                                                                                                                                      │
│4. Пользователь указывает, что  хочет получить (можно  указать не все): расчет трудозатрат на разработку, архитектурное решение,  длительность проекта, стоимость гарантии, стоимость тех поддержки, сайзинг, риски, НФТ ит.д.        │
│5. Пользователь получает список  вопросов для взаимодействия с  заказчиком и уточнения требований                                                                                                                                     │
│6. Пользователь вносит ответы на  заданные вопросы                                                                                                                                                                                    │
│7. Пользователь получает рекомендациипо вы архитектуре и выбранным решениям                                                                                                                                                           │
│8. Если вариантов несколько, то  пользователь указывает выбранный  вариант решения                                                                                                                                                    │
│9. Пользователь получает результат в соответствии с требованиями  п 4. настоящего раздела.                                                                                                                                            │
